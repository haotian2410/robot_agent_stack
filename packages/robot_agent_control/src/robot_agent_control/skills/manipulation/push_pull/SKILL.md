# Push / Pull Skill

执行一个有界的局部接触推拉动作。技能包含带关节机构操纵和自由物体推动两种交互模式。

## 使用边界

- `Move` 负责到达预接触位姿及操作后的自由空间撤离。
- `mechanism` 模式要求夹爪已夹持把手或接触部件，负责让末端与铰链/滑轨机构沿同一条 hard 几何轨迹运动。
- `free_object` 模式要求夹爪未抓持任何物体、目标具有自由关节，并且预接触位姿已经形成真实指垫接触；只支持沿表面法向推动，不支持无抓取拉动。
- 两种模式都负责维持预期接触、监测力和行程、处理接触丢失或卡滞，并验证目标确实移动。
- 仅移动末端而不操纵物体时使用 `Move`。
- 不负责检测目标、估计接触点、生成轨迹几何或控制夹爪抓取。

## 策略

- `linear_push_pull`：沿单位方向推或拉带滑轨机构，适用于抽屉和滑块。
- `circular_push_pull`：绕给定中心和轴运动指定角度，适用于门、铰链和旋转机构。
- `free_object_push`：指垫保持接触并与自由物体同步直线平移，适用于桌面箱体、方块和其他可平移物体。

轨迹几何均为 hard 约束，不得为避障静默改变。推拉方向由 `operation` 解释：请求中的方向始终表示末端实际运动方向，不由技能自动反号。

直线策略将请求的世界/基坐标方向与滑轨轴比较：同向增加滑轨位移，反向减小滑轨位移。因此同一抽屉使用相反的 `direction` 即可执行拉开和推回；方向与滑轨轴不共线时必须失败。

自由物体模式使用 `target.type=object` 和 `manipulation.interaction_mode=free_object`。`target.contact_normal` 必须是物体表面向外法向量，实际 `direction` 必须与其反向共线。该模式保持物体世界姿态不变，只执行居中的准静态直线平移；不用于倾倒、滚动、旋转或偏心推物。若需要拉动，必须先抓取并使用机构/抓持语义。

末端局部 Z 轴是本技能的工具方向轴。执行前及整个推拉轨迹中，该轴必须与目标接触点法向量共线；允许同向或反向。直线策略保持法向姿态，圆弧策略让末端姿态和接触法向量随机构绕圆弧轴同步旋转。超过 `normal_alignment_tolerance` 时立即停止并返回失败，不得以固定世界姿态继续运动。

`avoid_collision` 必须为 `true`。执行前和每个插值点都要复检机械臂、夹爪、目标与环境的接触。机构模式仅允许指垫—指定把手接触；自由物体模式仅允许起点已有的指垫—目标接触和与推动方向正交的已有支撑接触。新增接触、穿透加深、接触丢失或支撑面丢失时，恢复到上一安全状态并立即失败。

仿真抽屉内的自由物体可通过 `strategy_params.carried_objects` 声明。控制器在抽屉平移时保持这些物体与抽屉的相对位移，并将物体—抽屉托盘的轻微支撑接触视为预期接触；其他载荷碰撞仍会触发回滚。

## 执行流程

```text
校验请求 → 获取同步状态 → 选择策略 → 检查夹爪已夹持目标及控制器状态
→ 建立并维持接触 → 执行有界轨迹 → 验证目标位移/转角 → 返回结构化结果
```

任何最大力、最大行程、超时、接触丢失或控制器故障都必须停止前进。只有在错误可恢复、机器人状态安全且显式允许时才能回到预接触位姿。
